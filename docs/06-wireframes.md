
# Wireframes – DemaciaHub

## 1. Tournament Bracket

![Tournament Bracket](../wireframes/DemaciaHub-bracket.jpg)

Wireframe prikazuje bracket izbranega turnirja, kjer lahko uporabniki spremljajo potek tekmovanja in napredovanje ekip skozi posamezne kroge. Prikazani so pari ekip, rezultati tekem ter povezave med posameznimi krogi, od prvega kroga do finala.

## 2. Match

![Match](../wireframes/DemaciaHub-match.jpg)

Wireframe prikazuje podrobnosti posamezne tekme znotraj turnirja. Na zaslonu sta prikazani obe sodelujoči ekipi (Team Blue in Team Red), skupaj s seznamom petih igralcev na vsaki strani ter Chat room za pogovor z ostalimi igralci in adminom. Pri posameznem igralcu so predvideni prikaz uporabniškega imena, njegovega ranka in informacije pridobljene iz RIOT API-ja.

## 3. Tournament Creation

![Tournament Creation](../wireframes/DemaciaHub-tournament-creation.jpg)

Wireframe prikazuje obrazec za ustvarjanje novega turnirja, ki je namenjen organizatorjem. Obrazec omogoča vnos osnovnih podatkov, kot so ime turnirja, datum začetka, število sodelujočih ekip, opis turnirja in pravila tekmovanja.

V spodnjem delu zaslona je prikazan seznam administratorjev, kjer lahko organizator doda dodatne osebe za pomoč pri upravljanju turnirja.
