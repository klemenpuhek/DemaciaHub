# 0002 – JavaScript na frontendu in backendu

## Kontekst in problem
Za uporabniški vmesnik in strežniško logiko potrebujemo programski jezik.

## Obravnavane alternative
- JavaScript na obeh straneh
- JavaScript na frontendu in PHP na backendu

## Sprejeta odločitev
Izbrali smo **JavaScript na obeh straneh**, ker en jezik poenostavi razvoj in deljenje podatkovnih struktur.

## Posledice
- **Pozitivno:** Manj preklapljanja med jeziki.
- **Negativno:** Za preverjanje tipov je potrebno dodatno paziti med razvojem.
