# 0003 – Node.js in Express.js za backend

## Kontekst in problem
Aplikacija potrebuje strežnik za prijavo uporabnikov, upravljanje ekip in izvajanje pravil turnirjev.

## Obravnavane alternative
- Node.js in Express.js
- PHP in Laravel

## Sprejeta odločitev
Izbrali smo **Node.js in Express.js**, ker omogočata preprosto izdelavo REST API-ja v JavaScriptu.

## Posledice
- **Pozitivno:** Enak jezik na frontendu in backendu ter preprosto definiranje API poti.
- **Negativno:** Preverjanje vhodnih podatkov in organizacijo kode moramo urediti sami.
